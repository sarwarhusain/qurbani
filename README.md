QurbaniHat

QurbaniHat is a modern web application built with Next.js that allows users to browse, view, and book animals for Qurbani purposes. It provides a smooth and user-friendly experience with authentication, detailed animal pages, and a booking system. Users must log in to make a booking, ensuring secure access and management of data. The platform is designed to simplify the process of selecting and managing Qurbani animals online.

Live URL: https://qurbani-three.vercel.app

Key Features include user authentication using Better Auth, animal listing with detailed views, booking form with validation, login-protected actions, responsive design, modern UI using HeroUI, Tailwind CSS, and DaisyUI, image optimization with Next.js Image, animations using Animate.css, and interactive UI elements like Swiper sliders and toast notifications.

Technologies used in this project include Next.js, React, Tailwind CSS, DaisyUI, HeroUI, MongoDB, Better Auth, Swiper, React Icons, React Toastify, and Animate.css. Development tools include ESLint, Tailwind PostCSS, Gravity UI Icons, and Babel React Compiler.

To run the project locally, clone the repository, install dependencies using npm install, configure environment variables including BETTER_AUTH_URL and MONGODB_URI, then run npm run dev. For production, use npm run build and npm start
